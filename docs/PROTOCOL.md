# 次段階の試験プロトコル（未実施）

## 研究デザイン

同じ初期モデル、データ順序、総学習計算予算、構造変更候補と探索予算を使用する。FFNに限ったゲートなど、特定位置にのみ圧力を掛けない。構造の縮小位置・削減率は事前固定しない。

| 実験群 | 選択圧 | 目的 |
|---|---|---|
| C（対照） | 未知検証データでの損失 | 通常探索による圧縮との差 |
| E（エネルギー） | 検証損失 + 実測J/token | エネルギー制約固有の効果 |
| P（サイズ） | 検証損失 + 保存パラメータ数 | 単純なサイズ最小化との差 |

選択係数はテストセットを見ずに校正データで決める。ハイパーパラメータ探索の総計算予算を含め、3群をそろえる。許容する構造変更は3群で等しい。

## 主要評価

- 未知テストデータの次トークンクロスエントロピー。
- 同一ハードウェア、バッチ、入出力長、クロック、dtype、バックエンドでの実測J/generated token。
- 物理的に保存する総パラメータ数（共有重みの重複計数を防ぐ）。
- 副次評価：token/s、ピークRAM/VRAM、モデルサイズ、学習・探索のエネルギー。

### 次元チェック

`E = ∫P(t) dt`、W=J/sであるため W×s=J。演算数や転送バイト数は較正せずにJと等しいと置けない。

## H / T / D / C / U

- **H:** 品質非劣性を満たした上でE群がC群よりJ/tokenと保存パラメータ数を両方低減する。
- **T:** 最初に探索的な少数シードで動作確認。その後、事前登録した検証セット分割と20シード以上の確証試験を行う。
- **D:** 品質非劣性マージン、J/token改善率、サイズ改善率、信頼区間、逐次停止条件を**結果を見る前に**事前登録してPASS/FAIL/UNCERTAINを判定。
- **C:** サイズ圧力だけで同じ小型化が可能、あるいは電力モード/量子化だけがJ/tokenを下げる。
- **U:** シード、温度、周波数、計測分解能、アイドル消費、装置境界、入力長。合成不確かさを算出する場合は各標準不確かさと包含係数kを明記。

## 測定上の規律

外部電力計を優先し、CPU packageならRAPL、GPUなら対応する総エネルギーカウンタを使う。どの回路を含むか明記。測定不能ならJ/tokenの実測結果を主張しない。ウォームアップ後、条件をランダムに交互配置して反復し、クロック・温度・電力モードと測定値を記録する。
