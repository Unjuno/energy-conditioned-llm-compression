# 研究仮説（2026-11-19）

## 中心仮説

**LLMの学習中に推論エネルギーへの選択圧を与えると、未知データに対する予測性能を保持しつつ、内部計算と表現の冗長性が減少し、物理的に保存するパラメータ数も削減される可能性がある。**

反証可能な仮説であり、実証済みの事実ではない。神経系の代謝制約は着想源であり、脳とTransformerが同じ最適化機構を持つとは仮定しない。

## 分割仮説

- **H1（省エネルギー適応）**：同一の未知データ性能下で、実測推論 J/token が低下する。
- **H2（構造圧縮）**：H1の選択圧により、保存される物理パラメータ数も減少する。
- **H3（表現効率）**：同じ保存パラメータ数と学習予算なら、エネルギー制約付き学習群の未知データ性能が同等以上になる。

H1はH2もH3も含意しない。低ビット化や条件付き実行なら、保存するパラメータ数が変わらずにエネルギーが減りうる。

## 操作的定義

| 用語 | 定義 |
|---|---|
| 推論エネルギー | 測定対象装置と区間を明示した電力量（J）およびJ/generated token |
| 保存パラメータ数 | 配布するモデルのテンソルに物理的に保持される要素数（タイド重みは二重計数しない） |
| クリーン | **同じ未知データ性能に必要な冗長性が少ない**状態。人が重みの意味を理解できるという意味とは区別 |
| 推論速度 | s/token, token/s。J/tokenとは異なる |
| 総コスト | 学習・構造探索・推論のエネルギーを別々に測定する |

## 反証につながる観測

1. 省エネルギー化しても保存パラメータ数が減らない → H2支持なし。
2. 小型化しても未知データ性能の低下が許容幅を超える → 主成功条件に不合格。
3. エネルギーの代理量しか取得できない → H1はUNCERTAIN。
4. 同数パラメータの通常学習群に表現効率で劣る → H3支持なし。

## 関連分野

- 進化神経科学：神経情報処理の代謝制約。
- 機械学習：構造探索、表現学習、正則化、パラメータ共有。
- 計算機アーキテクチャ：メモリアクセス、演算、電力と実行時間。
