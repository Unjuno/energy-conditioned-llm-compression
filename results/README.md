# Pilot results (archival)

These tables are **exploratory** and **do not contain measured joules**. `energy_pilot_summary.csv` records aggregate observations extracted from the 2026-11-18 exploratory structural-search trial. See [pilot findings](../docs/PILOT_FINDINGS.md) before interpretation.

- Three seed labels represent **candidate selection / evaluation** conditions, not independent retraining runs.
- Model weights were fixed. No during-training energy pressure was implemented.
- Raw data, third-party source models and local machine logs are not included in this public repository.
- Legacy per-run JSON/CSV and plotting scripts remain in the locally prepared research archive and can be added after provenance and publication checks.

The data are not a benchmark of energy-constrained learning.
